# LessonViewer 학습 모듈

## 기준

2026-11-08 사용자가 현재 앱을 디자인 기준으로 지정했다. 외부 레퍼런스 선행 조건 대신 기존 원본·해설 읽기 흐름을 유지한다. Notefolio의 학습/AI/서비스 검색에서는 적합한 공개 Figma 파일을 찾지 못했다. 무관한 쇼핑몰 포트폴리오는 사용하지 않았다.

Figma 설계: https://www.figma.com/design/Uguit1ehM9CoKk0nVgTAPW
- 1:2: 원본·해설·학습 대화
- 2:2: 자료 등록·생성·검토
- 3:2: 좁은 화면의 읽기와 질문 진입

화면은 편집 가능한 텍스트와 레이아웃으로 구성해 검토했다. Figma의 예시 강의 문구는 배치 확인용이며 제품은 실제 PDF와 서버 응답만 표시한다.

## 화면 계약

- 학습 화면의 일: 원본을 읽고 설명을 확인한 뒤, 막힌 부분을 근거와 함께 질문한다.
- 자료 관리의 일: PDF를 등록하고 생성 결과를 검토해 게시한다. 원본 등록과 유료 생성 시작은 별도 행동이다.
- 객체: 원본 쪽, 해설, 학습 흐름, 생성 작업, 대화, 출처 쪽, 읽기 상태.
- 순서: 자료 선택 → 원본·해설 → 현재 쪽을 아는 질문 패널. 자료 생성은 등록 → 생성 → 검토 → 게시.
- 기존 자료·필기·책갈피·별표·실습은 유지한다. 생성한 코드는 실행하지 않는다.
- 화면에 넣지 않은 것: 결제, 호스트 서비스 로그인, 조직 관리, 클라우드 코드 실행.

## 시각 규칙

기존 Montserrat + 경기천년제목 글꼴 체계를 유지한다. 원본 PDF의 내장 글꼴은 바꾸지 않는다. 한국어 읽기 본문은 16px, 약 1.7 행간을 기준으로 한다. 긴 코드·표는 컨테이너 안에서 스크롤한다. 기존 글꼴은 로컬 설치 또는 기존 번들에서 사용하며 새 글꼴을 외부 CDN에서 받지 않는다.

색상은 `web/src/styles.css`의 의미별 토큰을 사용한다. 빨강은 선택·주요 동작, 파랑은 인용·보충, 중립색은 읽기 진행도이다. 밝은 모드의 본문 `#1b2232`, 보조 텍스트 `#4f596c`, 메타데이터 `#606b7d`를 기준으로 하며, 어두운 모드에서도 별도 대비 색을 사용한다. 새 모듈 스타일은 `module.css`, 기존 학습 화면의 에이전트 배치는 `integration.css`에 있다.

사이드바는 학습·자료 관리의 고정 진입점과 과목 전환을 분리한다. 읽은 비율과 현재 선택은 서로 다른 표시를 사용한다. 장식적인 등장 효과 대신 짧은 상태 전환을 쓰며 reduced motion을 존중한다.

대화 패널은 데스크톱에서 읽기 영역 옆에, 작은 화면에서는 별도 dialog로 열린다. 패널 닫기와 답변 중지는 별개다. 닫았다 열어도 작성 중인 질문과 진행 중인 답을 유지한다. 짧은 화면에서는 패널 자체를 스크롤해 입력란에 접근한다.

## 상태와 신뢰 경계

- API 미설정: 원본 등록·읽기는 유지하고 생성·질문 불가 이유를 표시한다.
- 생성 중: 단계와 완료한 쪽 수, 취소 동작을 표시한다.
- 실패: 원본·입력·작업 기록을 보존하고 명시적 재시도를 제공한다.
- 완료: 후보 해설이며 게시 전에는 기존 해설을 바꾸지 않는다. 현재 게시본은 문서의 `published.jobId`로 판단한다.
- 대화: 답변·중단·실패를 구분하고 실제 조회한 쪽만 인용 버튼으로 표시한다. 이는 문장 전체의 사실성 인증이 아니다.
- 생성된 Markdown의 이미지 로드를 막고, 외부 자료 안의 지시를 실행하지 않는다.
- 진행 기록 저장 실패는 숨기지 않는다. 다시 저장할 수 있으며 로컬 학습과 자료 관리 간 이동에도 실패한 기록을 유지한다.
- 모델 키는 서버에만 둔다. 호스트 신원은 인증된 서버 요청에서만 받아들이며 개인용 강의와 호스트 workspace를 분리한다.

## 실제 확인한 범위

- TypeScript 검사, 서버 테스트 44개, 기존 해설 pack 83개 검증(오류·경고 0), Vite 빌드.
- 실제 Anthropic `claude-sonnet-5-5` API: 기존 강의 2쪽 PDF 추출, 전체 쪽 해설과 흐름 생성, 후보 조회, 게시, 문서 대화 스트리밍·저장·인용 1/2쪽.
- 기존 강의 10쪽을 출처로 한 브라우저 질문과 근거 응답, 별표 저장(격리한 검증 DB).
- 브라우저에서 PDF 업로드, API 미설정 상태, 작성 중 질문을 닫았다 열어도 유지, 390px 폭에서 수평 넘침 없음, 340px 높이에서 대화 입력란 접근.
- 1440px 데스크톱 학습 홈·문서 읽기·대화 패널, 밝은/어두운 테마 화면 확인.
- `/lessonviewer/?embed=1#/library/...` 경로의 임시 호스트 프록시: 정적 파일·API·원본 이미지 로드, 개인용 사이드바 미노출.
- 인증 없는 프록시 요청·cross-site 변경 요청 거절, 호스트의 로컬 강의/문서 접근 차단, workspace 간 분리.
- 생성된 Markdown의 외부 이미지가 `<img>`로 렌더링되지 않는지 확인.

OpenAI-compatible 어댑터는 프로토콜 단위 테스트로 확인했으며 실제 제공자 호출은 Anthropic에서 수행했다. 특정 호스트 서비스 연결·실제 사용자 로그인·공개 배포·부하 검증은 수행하지 않았다. 호스트 서비스 편입 시 그 서비스의 인증 프록시와 저장 정책을 연결해야 한다.
